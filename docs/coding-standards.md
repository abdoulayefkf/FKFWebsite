# Coding Standards

- Keep strict TypeScript; do not use `any`.
- Prefer Server Components. Add `"use client"` only for browser state or interaction.
- Reuse shared components and typed content instead of duplicating page markup.
- Use semantic HTML, descriptive alternative text, visible focus states, and keyboard-operable controls.
- Use `next/image` for local photography and `next/link` for internal navigation.
- Preserve FKF’s gold, white, and black identity and authentic images.
- Do not add inline styles, logs, unused imports, or broken links.
- Run lint and production build before review.

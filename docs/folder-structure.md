# Folder Structure

- `app/`: routes, root layout, global CSS, robots, and sitemap
- `components/layout/`: navigation, footer, page hero, and global interactive UI
- `components/sections/`: homepage and reusable page sections
- `components/ui/`: shadcn-based primitives
- `lib/`: typed content and utilities
- `public/`: authentic FKF imagery, logos, and static assets
- `docs/`: architecture, onboarding, deployment, and roadmap guidance

Add new public static page copy to `lib/site-content.ts`. Use a dedicated route/component only when a page genuinely needs a distinct interaction or layout.
